# Sentiment Analysis

Analyze whether a text is **positive**, **negative**, or **neutral** using VADER sentiment analysis.

## Features
- Command-line input
- Polarity classification: positive, negative, neutral
- Confidence + compound score output

## Setup

```bash
pip install -r requirements.txt
```

## Usage

```bash
python main.py --text "I love how clean and fast this tool is."
```

## Example Output

```text
Sentiment Analysis Result
Label: positive
Confidence score: 0.612
Compound score: 0.862
```
